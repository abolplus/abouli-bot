# Telegram Group Game Bot - Test Build

1. Python 3.11+ نصب کنید.
2. `pip install -r requirements.txt`
3. `.env.example` را به `.env` تبدیل کنید و BOT_TOKEN را وارد کنید.
4. CHANNEL_ID را با شناسه عددی کانالی که کامنت‌های آن باید پاداش داشته باشند تنظیم کنید.
5. اجرا: `python game_bot.py`

نکته: برای دریافت کامنت‌های کانال، ربات باید به کانال و discussion group دسترسی مناسب داشته باشد. این نسخه هسته بازی گروهی و سیستم پاداش کامنت را دارد.
